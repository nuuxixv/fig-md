# Fig.md 수동 QA (실제 Figma)

> Liquid Glass 리디자인 + "페이지 배경" 테마 모델 반영판. 실제 Figma 데스크톱 앱에서 진행.

## 설치·기본 표시
- [ ] manifest import 성공, 패널 표시
- [ ] 패널이 Liquid Glass 느낌(반투명 유리, 큰 concentric 라운드, 상단 스펙큘러 하이라이트)으로 보임
- [ ] 패널 폰트가 Pretendard(설치돼 있으면) 또는 자연스러운 시스템 폴백(SF Pro/맑은 고딕 등)으로 표시되고 깨진 글자 없음

## 테마 — 패널·문서 모두 "페이지 배경" 따름
- [ ] 라이트 배경 페이지에서 패널 열기 → 패널 라이트, "프레임 만들기"로 렌더한 문서도 라이트
- [ ] Figma 페이지 배경색을 어두운 색으로 변경 → 패널을 닫았다 다시 열기(또는 재렌더) → 패널이 다크로 전환됨
- [ ] 같은 다크 배경 페이지에서 렌더 → 문서 프레임도 다크(배경/글자/구분선/콜아웃/코드블록 색 모두 다크 토큰)
- [ ] 페이지 배경이 채도 높은 색(예: 진한 보라)이어도 패널이 그 색을 그대로 칠하지 않고 밝기 판정만 반영(중립 유리 팔레트 유지)
- [ ] (참고) 페이지 배경을 바꾼 뒤 패널을 닫지 않고 그대로 두면 즉시 반영되지 않을 수 있음 — 재렌더 또는 재오픈 시 반영은 정상(라이브 구독은 의도적으로 보류됨, DESIGN.md 참고)

## 렌더 — 마크다운 → 프레임
- [ ] 대표 PRD 마크다운 붙여넣기 → "프레임 만들기" → 세로 오토레이아웃 프레임 생성
- [ ] 제목(H1/H2/H3)·본문·굵게·링크가 시각적으로 구분됨
- [ ] 인용(`>`)이 낮은 위계의 콜아웃 배경으로 렌더됨
- [ ] 코드 블록이 회색 박스(모노스페이스)로 렌더됨
- [ ] 표가 그리드로 렌더되고 셀 높이가 행 내에서 동일함(첫 행 헤더 구분)
- [ ] 구분선(`---`)이 얇은 가로선으로 렌더됨

## 컨텍스트 "+" 삽입
- [ ] 텍스트 영역이 포커스되기 전에는 "+" 버튼이 비활성 상태
- [ ] 포커스 후 "+" 클릭 → 유리 팝오버가 열림(구분선 / 표 옵션)
- [ ] "구분선" 클릭 → 커서 위치에 `---` 삽입, 팝오버 닫힘
- [ ] 표 규격에 `3x2` 입력 후 삽입 → 커서 위치에 3행(헤더 1 + 본문 2) × 2열 표 스켈레톤(`| 헤더1 | 헤더2 |` 등)이 삽입됨
- [ ] `×` 문자로 입력해도(`3×2`) 동일하게 동작
- [ ] 삽입된 구분선/표를 "프레임 만들기"로 렌더 → 정상적으로 그려짐
- [ ] Esc 또는 팝오버 바깥 클릭 → 팝오버 닫힘

## 색상 직접 지정
- [ ] 토글 OFF 상태로 렌더 → 문서가 현재 페이지 배경 판정(라이트/다크)을 따름
- [ ] 토글 ON → 배경/글자 커스텀 색 피커 펼쳐짐, 미리보기에 실시간 반영
- [ ] 커스텀 배경/글자색 지정 후 렌더 → 문서가 페이지 배경 판정 대신 지정한 색을 사용

## 마크다운 추출(export)
- [ ] 캔버스에서 제목 텍스트를 직접 수정 → 추출 시 수정 내용이 반영됨
- [ ] 블록 순서를 드래그로 바꾼 뒤 추출 → 순서가 반영됨
- [ ] "마크다운 추출" 클릭 → 클립보드에 유효한 마크다운이 복사됨(토스트로 완료 안내)
- [ ] 추출 결과를 노션/협업툴에 붙여넣기 → 서식이 깨지지 않음(제목/굵게/링크/표/코드블록 정상)

## 이물질(태그 안 된 노드) 처리
- [ ] Fig.md 페이지 프레임 안에 사각형 등 직접 그린 노드를 추가하고 추출
      → 경고 메시지에 해당 노드가 뜨고, 추출된 마크다운에는 포함되지 않음

## 알려진 한계(재확인용 — 버그 아님)
- [ ] Pretendard는 플러그인에 임베드되어 있지 않음 — 사용자 시스템에 없으면 자동으로
      시스템 폰트(SF Pro/맑은 고딕 등)로 폴백됨. 폴백 상태에서도 레이아웃이 깨지지 않는지 확인
- [ ] Figma 플러그인은 iframe이라 뒤의 Figma 캔버스를 실제로 blur 비침 처리할 수 없음 —
      패널은 자체 단색 무대(페이지 배경 기반) 위에서 반투명·하이라이트로만 유리감을 냄.
      "캔버스가 비쳐 보여야 한다"는 기대로 리포트하지 않기
