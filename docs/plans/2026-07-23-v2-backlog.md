# Fig.md v2 백로그 (계획만, 미구현)

v1(라운드트립 코어)은 완료·머지됨. 아래는 실기기 QA에서 나온 개선 요청 + 이월 항목.
**전면 디자인 개선과 함께 진행 예정**이라 지금은 기획만 한다.

## 1. 캔버스 배치 UX (2026-07-23 요청)

### 1.1 현재 화면(뷰포트)에 생성
- **문제:** 렌더 시 새 페이지 프레임이 항상 캔버스 `(0,0)`에 생성돼, 사용자가 보고 있는 위치와 동떨어짐.
- **접근:** `src/code.ts`의 `render` 핸들러에서, 프레임을 `currentPage`에 append한 뒤 실제 노드의 `x/y`를 뷰포트 안으로 설정.
  - `const b = figma.viewport.bounds;` (보이는 영역 사각형 {x,y,width,height})
  - `node.x = Math.round(b.x + 40); node.y = Math.round(b.y + 40);` (뷰포트 좌상단 근처)
  - 또는 가로 중앙 정렬: `node.x = Math.round(figma.viewport.center.x - node.width / 2);`
- 페이지 프레임은 `currentPage`의 직속 자식(오토레이아웃 부모 아님)이라 `x/y` 직접 설정 가능.
- 코어(`renderDoc`) 무관 — code.ts에서만 처리. `FigmaLike` 인터페이스 변경 불필요.
- **QA:** 실기기에서만 검증 가능(뷰포트는 FakeFigma로 모델링 안 함).

### 1.2 여러 개 생성 시 오른쪽에 자동 타일링
- **문제:** 렌더는 매번 새 프레임을 만드는데(§4.1 전체 재생성), 전부 `(0,0)`에 겹쳐 쌓임.
- **접근:** `src/code.ts`에서 렌더 직전 기존 Fig.md 페이지 프레임 수집 후 오른쪽에 배치.
  - `const pages = figma.currentPage.children.filter(isPageFrame);`
  - `pages.length > 0` 이면: `node.x = Math.max(...pages.map(p => p.x + p.width)) + GAP;`
    (`GAP = 48`) `node.y =` 가장 위 프레임의 `y`에 정렬(`Math.min(...pages.map(p=>p.y))`).
  - `pages.length === 0` 이면 1.1(뷰포트 배치) 적용.
- 결과: 반복 렌더가 좌→우로 나란히 깔림(겹침 없음).
- **참고:** 별개 기능으로 "선택한 프레임을 제자리에서 다시 렌더(업데이트)"도 검토 가능(현재는 항상 신규 생성). §4.1 재렌더 정책과 함께.

## 2. 표 열 너비 제어 (2026-07-23 요청)
- **현재:** 모든 셀 `layoutSizingHorizontal='FILL'` → 균등 너비(합 720px).
- **옵션 A(추천, 소규모):** 앞 열들은 `HUG`(내용 맞춤), **마지막 열만 `FILL`**(남는 폭). 스펙표(라벨 열 좁게 / 설명 열 넓게)에 적합. `renderTable`에서 셀 사이징만 조정.
- **옵션 B(수동):** Figma에서 셀 선택 → 가로 리사이징 `Fill`→`Fixed` + 너비 지정(오토레이아웃이 나머지 재분배). 열 단위 선택이 번거로움.
- **옵션 C(대규모):** 열별 임의 너비를 마크다운/플러그인 UI로 지정 — 표준 마크다운에 없음. 재디자인 때.

## 3. 플러그인 디자인 전면 개선 (사용자 계획)
- 패널 UI(입력·버튼·미리보기) 리디자인.
- 렌더 결과의 시각 폴리시: 타이포 스케일, 색/간격 토큰, 제목/본문 위계, 인용 콜아웃 정교화, 코드블록 신택스 톤, 표 스타일(테두리·헤더·정렬) 등.
- 위 1·2를 이 단계에 통합해 일관된 UX로.

## 4. 이월된 v1 한계 · 마이너 (기록용)
- **제목(heading) 내부 인라인 서식** 왕복 미지원(제목은 렌더 Bold + 평문 읽기). 문단·목록은 지원. → 지원하려면 제목 읽기를 스타일 기반으로 바꾸되 "제목 기본 Bold"를 strong으로 오인하지 않도록 처리 필요.
- **`npm test`/`build`에 `tsc --noEmit` 게이트 미연결**(수동 실행 중) → CI/스크립트에 추가.
- **같은 레벨 혼합 목록 마커**(`-`와 `1.`)는 첫 항목 기준 한 타입으로 묶임.
- **인용 `>` 엣지**: 공백 없는 `>`, 빈 인용 줄은 정규화(경미).
- **앞 문단과 빈 줄 없이 붙은 표**는 문단에 흡수(마크다운 일반 동작).
- **`read.ts` 코드블록 읽기**: 구(舊) 버전이 남긴 TEXT 노드형 코드블록에 대한 방어 가드 없음(프리릴리스라 실사용 시나리오 낮음). `node.type !== 'FRAME'` 가드로 하드닝 가능.
- **`(tmp as unknown as FrameNode).remove()`** 이중 캐스트(코스메틱).
