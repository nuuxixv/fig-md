# Fig.md

피그마 프레임을 노션 페이지처럼 쓰는 마크다운 라운드트립 에디터.

## 개발
- `npm install`
- `npm test` — 코어/렌더/읽기/통합 테스트
- `npm run build` — `dist/code.js`, `dist/ui.html` 생성

## 피그마에 로드
1. Figma 데스크톱 → Plugins → Development → Import plugin from manifest
2. 이 폴더의 `manifest.json` 선택
3. 플러그인 실행 → 마크다운 붙여넣기 → "마크다운 → 렌더"
4. 캔버스에서 편집 → 페이지 프레임 선택 → "익스포트 → 마크다운"(클립보드 복사)

## 범위
지원: 제목, 문단, 목록(중첩·체크박스), 인용, 구분선, 코드블록, 표, 이미지(플레이스홀더).
인라인 서식(굵게/기울임/코드/**링크**, 링크는 URL까지)은 **문단과 목록 항목 안에서 왕복**된다.
단, **제목(heading) 안의 인라인 서식은 v1 한계로 평문으로 렌더·출력**된다(굵게 등은 소실).
미지원(v1): 토글 접기, 표 행/열 편집, 실시간 동기화.
